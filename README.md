# README

My repository for the BNY Graduate Software Engineering Interview Exercise.

## Requirements

- Java 25
- Node.js 24
- Gradle

## Sources

- GNews API
- The Guardian API

API Keys stored locally in `application-secrets.properties` file.

## Run backend

`cd ./backend-api`

`./gradlew bootRun`

## Run frontend

`cd ./frontend`

`npm install` (install dependencies)

`npm run dev`
